About Our Project

This project all started between a few friends with a file found on GitHub and hopes to be able to actually have fun at school.

It has now turned into the numerous projects, tools, and other resources available on this website.

Started in November 2025, numerous hours have gone into not only this website, but the tools available on it.

We don't mind promotion or sharing of our work, but PLEASE do not rip our hard work as your own.

We have spent so much time on this project and are glad to have the ability to share it.

We also appreciate all the help and tips that users have given us to be able to create better, more powerful tools. Without the users, this project wouldn't be where it is today.
