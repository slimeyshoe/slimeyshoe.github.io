About Our Project

This project all started between some friends trying to play games at school.
It has now turned into the projects, tools, and other resources available on this website (and even more coming cuz we're tuff!)



This project started early in our 2025 school year due to a state-wide cellphone ban in schools.
It started as a shared Google Doc where we would put links to game websites or anything else we found useful. However, a problem arose quickly.
School devices are insanely locked down. Some don't even allow HTML files or ANY non-permitted links.
Met with all of these security measurements, we had to find a way to access blocked links, so we started The Shoe Shelf.
We never knew we would make so many tools of our own, even including a game site, but we are proud of the work.



We don't mind promotion or sharing of our work, but PLEASE do not rip it as your own. That would suck for us.
We have spent so much time on this project and are glad to have the ability to share it.
We also appreciate all the help and tips that users have given us to be able to create better, more powerful tools.
Without the users, this project wouldn't be where it is today.
